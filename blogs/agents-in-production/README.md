# Agents in Production

Code for our five-part series on putting an AI agent into production with R: a clinical-trial safety assistant built with {ellmer}, {shinychat}, {vitals} and {mcptools}, on the public CDISC pilot study 01 data from {pharmaverseadam}.

Each folder is self-contained, with its own README, `renv.lock` and tests. Open the folder for the part you're reading as an RStudio or Positron project, then run `renv::restore()`.

| Folder | Post |
|---|---|
| `part-1` | [Build Your First AI Agent in R with {ellmer}](https://www.jumpingrivers.com/blog/agents-in-production-first-agent/) |
| `part-2` | [Build an AI Chat App with Shiny and {shinychat}](https://www.jumpingrivers.com/blog/agents-in-production-shiny/) |
| `part-3` | [How to Test and Evaluate an AI Agent in R](https://www.jumpingrivers.com/blog/agents-in-production-trust/) |
| `part-4` | [Audit Trails and Cost Control for AI Agents in R](https://www.jumpingrivers.com/blog/agents-in-production-running/) |
| `part-5` | [Build an MCP Server in R with {mcptools}](https://www.jumpingrivers.com/blog/agents-in-production-mcp/) |

You'll need a Gemini API key; each part's README says where it goes.
